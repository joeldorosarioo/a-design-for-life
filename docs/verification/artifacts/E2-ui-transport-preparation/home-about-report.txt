## Scope and public props

- `src/features/professional-profile/ui.ts` exports `HomeContent`, `HomeContentProps`, `AboutContent`, `AboutContentProps`. The contracts `index.ts` stays free of UI/CSS imports.
- `HomeContent({ profile: ProfileDTO, projectsHref: string, aboutHref: string, featuredProjects: ReactNode, mediaMode?: 'published' | 'preview' })`.
- `AboutContent({ profile: ProfileDTO, projectsHref: string, mediaMode?: 'published' | 'preview' })`.
- Composition supplies validated localized navigation hrefs and the Cases-owned featuredProjects slot. These presenters do not resolve URLs, query the CMS, duplicate Case data or invent an empty-state message.
- `ProfileImage` is an internal helper with four closed slots: portrait (Home), about-portrait, desk, architecture. No style/size/CSS fields are exposed to editors.
- Default mediaMode is published; only preview sets Next Image unoptimized, preserving the authenticated original route rather than asking an anonymous optimizer to fetch a private image. Both presenters forward this mode.
- All image sources are `/media/{mediaId}/original` through real Next Image. Only image-use alt/caption are rendered. A decorative use emits alt="". Extra storage metadata is not spread into the DOM.
- Plain text is React-escaped; blank lines separate paragraphs and single newlines are retained with pre-line. Structured groups, semantic headings, supplied CTA labels and locale-independent section reading keys are preserved.
- Row data-reading-key uses the supplied readingKey; ordinals are display only. Missing legacy/draft row keys do not invent reading correspondences.
- Method keywords and three About section eyebrows consume the field-agent DTO changes with nullable legacy defaults. About introduction/closing headings retain accessible semantics but are visually hidden, matching the baseline's visible composition.
