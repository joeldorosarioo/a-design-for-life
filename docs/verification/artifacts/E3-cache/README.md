# E3.2 — contratos de cache no Next real

Preparação de prova; nenhum resultado do E2E é antecipado por este arquivo.

O runner coordenado deve preservar o log/exit do build e do Playwright, o resultado JSON e os anexos `E3-confirmed-cache-proof.json` / `E3-owned-next-output.txt`. Os anexos incluem BUILD_ID, versões observadas, namespace e IDs próprios, origens canônica/física separadas, fontes/SHA256 e estados/hashes das respostas. Não armazenar credenciais, cookies, auth state ou corpos de rascunhos.

Comando e limites em [publicacao-e-cache](../../../runbooks/publicacao-e-cache.md). O teste usa mídia local sintética, não R2 real. A conclusão dos cinco critérios E3.2 e a contagem da etapa permanecem a cargo do gate integrado/coordenador.
