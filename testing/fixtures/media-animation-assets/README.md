The upstream libavif tests/data/README.md attributes the AVIF fixture to libavif's BSD-2-Clause license. Its complete upstream LICENSE is preserved in `libavif-LICENSE.txt`. APNG fixtures were added by libvips' APNG support commit and have no separate individual license notice; the complete LGPL-2.1 repository license is preserved in `libvips-LICENSE.txt`.

The hidden APNG has a white default PNG image distinct from the first red animation frame. A successful static PNG decode therefore does not justify accepting it as a static upload. The cogs file has five animated frames; the hidden-default file has two.

WebP controls in `../media-animation.ts` are generated by actual Sharp encoding of synthetic solid-color/striped raw frames. Inputs have distinct red, green and blue frames, explicit delays and loop count; optional transparency and EXIF orientation exercise processing. No third-party WebP imagery is redistributed. Sharp's fixture encoder normalizes requested delays of 10 ms or less to 100 ms; tests use actual encoded input delays of 100/200/300 ms, never claim preservation of a pre-encoding request that is absent from the file.
